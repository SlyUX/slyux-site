# slyux.com

Stephen Fox's portfolio — Next.js 16 + Sanity v6, deployed on Vercel, DNS on Cloudflare.

```bash
cp .env.local.example .env.local   # then set NEXT_PUBLIC_SANITY_PROJECT_ID
npm install
npm run dev                         # http://localhost:3000, Studio at /studio
```

See `AGENTS.md` for conventions.
